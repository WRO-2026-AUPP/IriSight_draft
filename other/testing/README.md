# Testing evidence

This directory will store repeatable test procedures and evidence for the
International robot. Each recorded test should identify the date, robot
configuration, track configuration, procedure, measured result and conclusion.

Planned evidence categories include:

- Open Challenge runs in both directions
- Obstacle Challenge runs in both directions
- lap counting and automatic stopping
- parking entry and final position
- sensor calibration and distance checks
- mechanical, power and endurance checks

Parking entry is currently under test. Surprise Rule behavior is not yet
implemented, so neither should be recorded as complete.
