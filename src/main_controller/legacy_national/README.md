# National controller archive

This directory preserves the National Competition Jetson programs and BNO055
helper as development-history references.

These files target the former Intel RealSense D455 and ultrasonic-sensor
configuration. They are not compatible with the rebuilt International robot
and must not be used as its run commands or installation reference.

```text
legacy_national/
├── open_challenge/       National clockwise and counterclockwise programs
├── obstacle_challenge/   National clockwise and counterclockwise programs
└── sensors/              National BNO055 helper and saved calibration
```
