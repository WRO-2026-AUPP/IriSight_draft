# Obstacle Challenge programs

This is the destination for the current International clockwise and
counterclockwise Obstacle Challenge programs. They use the Hokuyo LiDAR, 1 MP
USB camera and rear VL53L0X sensor and still need to be copied from the Jetson.

The former RealSense- and ultrasonic-based programs are preserved under
[`../legacy_national/obstacle_challenge/`](../legacy_national/obstacle_challenge/).
Parking entry is currently being tested; Surprise Rule behavior has not yet
been implemented.
